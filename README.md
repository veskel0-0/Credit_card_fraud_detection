# Обнаружение мошеннических операций с кредитными картами (Credit Card Fraud Detection)

## Описание проекта
Данный репозиторий содержит исходный код и сопроводительную документацию к курсовой работе, посвящённой задаче выявления мошеннических транзакций при использовании кредитных карт. 

Проект представляет собой комплексное исследование, охватывающее все этапы работы с данными: от первичной очистки и разведочного анализа до построения прогнозной модели машинного обучения. Особое внимание уделено геопространственному анализу и методам отбора признаков на основе теории информации, что позволяет повысить интерпретируемость и точность модели в условиях сильного дисбаланса классов.

## Цель и задачи исследования
- **Цель:** Разработать модель бинарной классификации для выявления мошеннических транзакций и минимизации финансовых потерь эмитентов карт.
- **Задачи:**
  1. Проведение глубокого разведочного анализа данных (EDA) с выявлением пространственных и временных аномалий.
  2. Инженерия признаков с использованием геоинформационных расчётов (расстояние между держателем карты и торговой точкой).
  3. Строгий отбор информативных переменных методами теории информации (взаимная информация, энтропия).
  4. Построение и валидация нейросетевой модели классификации.
  5. Оценка качества модели с использованием ROC-анализа и метрики AUC.

## Исходные данные
- **Объём выборки:** 1.6 млн транзакций
- **Период:** 2020 год (июнь и последующие месяцы).
- **Ключевые признаки:**
  - `trans_date_trans_time` — дата и время транзакции
  - `cc_num` — анонимизированный номер карты
  - `merchant` — наименование торговой точки
  - `category` — категория покупки (personal_care, health_fitness, travel, food_dining и др.)
  - `amt` — сумма транзакции
  - `lat`, `long` — координаты держателя карты
  - `merch_lat`, `merch_long` — координаты торговой точки
  - `city_pop`, `job`, `dob` — социально-демографические характеристики
  - `is_fraud` — целевая переменная (0 — легитимная, 1 — мошенническая операция)

## Этапы выполнения работы

### 1. Предобработка данных
- Анализ пропусков и аномальных значений в числовых и категориальных полях.
- Преобразование форматов дат и времени для извлечения временных признаков (час, день недели, время суток).
- Кодирование категориальных переменных (регион, профессия, категория покупки).

### 2. Геопространственный анализ
- Визуализация географического распределения транзакций с использованием интерактивных карт (`leaflet`).
- Расчёт расстояния между местоположением держателя карты и торговой точкой (формула гаверсинусов через пакет `geosphere`).
- Выявление транзакций с аномально большими расстояниями как потенциальных индикаторов мошенничества.

### 3. Отбор признаков методами теории информации
- Расчёт взаимной информации (Mutual Information) между признаками и целевой переменной.
- Анализ энтропии и информационного выигрыша для каждого фактора.
- Использование пакетов `praznik`, `infotheo` и `Information` для количественной оценки значимости переменных.
- Формирование итогового набора признаков, свободного от мультиколлинеарности.

### 4. Построение модели машинного обучения
- Разработка архитектуры нейронной сети с использованием фреймворка `keras`.
- Обучение модели на сбалансированной выборке (с учётом дисбаланса классов).
- Оптимизация гиперпараметров и регуляризация для предотвращения переобучения.

### 5. Оценка качества модели
- Построение ROC-кривых и расчёт метрики **AUC** (Area Under the Curve) с помощью пакета `pROC`.
- Анализ матрицы ошибок (Confusion Matrix) для оценки долей истинно положительных и ложноположительных срабатываний.
- Демонстрация способности модели эффективно выявлять мошеннические операции при сохранении приемлемого уровня ложных срабатываний.

## Краткие выводы и итоги выполненной работы

В рамках исследования был реализован полный цикл анализа данных для задачи фрод-мониторинга:

1. **Предобработка данных:** очищен набор данных, преобразованы форматы дат и закодированы категориальные признаки для последующего моделирования.
2. **Разведочный анализ (EDA):** выявлены ключевые статистические закономерности. С использованием геоинформационных инструментов (`sf`, `geosphere`, `leaflet`) рассчитаны пространственные признаки (расстояние между геолокацией держателя карты и торговой точкой), которые служат важными индикаторами аномального поведения.
3. **Отбор признаков:** с применением методов теории информации (пакеты `praznik`, `infotheo`, `Information`) проведён строгий отбор наиболее релевантных переменных. Это позволило снизить размерность данных и повысить обобщающую способность модели.
4. **Моделирование:** разработана и обучена нейронная сеть на базе фреймворка `keras` для решения задачи бинарной классификации транзакций.
5. **Оценка качества:** валидация модели через ROC-анализ и метрику AUC подтвердила, что модель эффективно выявляет мошеннические операции, обеспечивая оптимальный баланс между долей истинно положительных срабатываний и уровнем ложных срабатываний — критически важное требование в условиях сильного дисбаланса классов.

Итогом работы стала работоспособная модель классификации и комплексный аналитический отчёт, демонстрирующий практическую применимость методов машинного обучения и геопространственного анализа для повышения безопасности финансовых операций.
